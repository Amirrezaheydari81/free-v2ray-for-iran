## 📌 درباره پروژه

این پروژه کانفیگ‌های V2Ray (شامل `vmess`، `vless` و سایر پروتکل‌ها) را از منابع معتبر جمع‌آوری کرده و به صورت **یکجا** در یک صفحه وب ساده ارائه می‌دهد.

> ⚡ **آپدیت خودکار:** هر ۲ ساعت توسط GitHub Actions

---

## ✨ ویژگی‌ها

- 🔄 آپدیت خودکار کانفیگ‌ها هر ۲ ساعت
- 📋 کپی سریع با `Ctrl+A` و `Ctrl+C`
- 🗺️ سایت‌مپ برای ایندکس سریع گوگل
- 🔔 اطلاع‌رسانی به گوگل با IndexNow
- 🌐 پشتیبانی از RTL و فونت فارسی وزیرمتن

---

## 🚀 نحوه استفاده

1. وارد **[صفحه کانفیگ‌ها](https://amirrezaheydari81.github.io/free-v2ray-for-iran/)** شوید
2. روی تکست‌اریا کلیک کنید
3. `Ctrl+A` (انتخاب همه) → `Ctrl+C` (کپی)
4. توی کلاینت V2Ray خودتون Paste کنید
